دليل الاستخدام

البداية السريعة المصادقة الربط مع كل أداة شكل الردود الحدود وفترات الانتظار باقات API نقاط الوصول رموز الأخطاء أمثلة برمجية

البداية السريعة

  1. أنشئ مفتاح API من الأعلى واحفظه في متغير بيئة على خادمك باسم POP_KEY.
  2. أرسل أول طلب لمعرفة باقتك وحدودك.
  3. استخدم نقاط الوصول بالأسفل، وتابع الحدود من ترويسات الرد.
export POP_KEY="pop_yourname_XXXXXXXXXXXXXXXXXXXXXXXXXXXXXXXX"
curl {BASE}/me -H "Authorization: Bearer $POP_KEY"

المصادقة

أرسل المفتاح في كل طلب داخل الترويسة Authorization بهذا الشكل: Bearer ثم المفتاح. ويمكنك بدلًا من ذلك استخدام الترويسة X-API-Key. يكون شكل المفتاح دائمًا: pop_ ثم اسم المستخدم ثم سلسلة عشوائية فريدة من 32 حرفًا.

Authorization: Bearer pop_ahmed_7Gk2Lm9QwXz4Rt8Vb1Nc6Hy3Pd5Fs0Ja
X-API-Key: pop_ahmed_7Gk2Lm9QwXz4Rt8Vb1Nc6Hy3Pd5Fs0Ja
  • استخدم المفتاح من خادمك فقط. الطلبات المباشرة من المتصفح محظورة عمدًا حتى لا ينكشف المفتاح لزوار موقعك.
  • يمكنك إنشاء حتى 3 مفاتيح في حسابك، مثلًا مفتاح لكل موقع أو خادم. كل المفاتيح تشترك في حدود حسابك اليومية، ويمكنك إلغاء أي مفتاح وحده دون التأثير على الباقي.
  • يظهر المفتاح كاملًا مرة واحدة فقط عند إنشائه، فاحفظه فورًا في مكان آمن.
  • لا تضع المفتاح أبدًا في رابط الطلب، مثل ?key=، فالروابط تُحفظ في السجلات. أي طلب يحمل المفتاح في الرابط يُرفض.
  • يمكنك تقييد كل مفتاح بعناوين IP خوادمك من الأعلى، فلا يعمل من أي مكان آخر.

شكل الردود

كل الردود بصيغة JSON وباللغة الإنجليزية. عند النجاح يكون الحقل ok بقيمة true والبيانات في data، وعند الخطأ يكون ok بقيمة false وتفاصيل الخطأ في error.

{
  "ok": true,
  "data": { },
  "meta": {
    "api_plan": "pro",
    "account_plan": "pro",
    "tier": "pro",
    "key": "My server",
    "requests_left_minute": 29,
    "requests_used_today": 1,
    "requests_left_today": 1999,
    "daily_limit": 2000
  }
}
{
  "ok": false,
  "error": {
    "code": "cooldown",
    "message": "This tool is in its cooldown period for your plan. Retry after the indicated time.",
    "retry_after": 1260,
    "available_at": "2026-11-12T11:00:00.000Z"
  }
}

الحدود وفترات الانتظار

لكل باقة API عدد طلبات في الدقيقة وفي اليوم. وتحصل كل أداة مدفوعة على حدود الباقة المقابلة لباقة API لديك، بنسبة أقل من حدودها في الموقع للحفاظ على استقرار الخوادم. ويوضح كل رد ما تبقى لك في هذه الترويسات:

الترويسةالمعنى
X-RateLimit-Limit-Minuteعدد الطلبات المسموح في الدقيقة.
X-RateLimit-Remaining-Minuteالطلبات المتبقية في الدقيقة الحالية.
X-RateLimit-Limit-Dayعدد الطلبات المسموح في اليوم.
X-RateLimit-Remaining-Dayالطلبات المتبقية اليوم.
Retry-Afterعدد الثواني قبل إعادة المحاولة، ويظهر مع الرمز 429.
X-Request-Idمعرّف فريد للطلب يفيد عند المتابعة.

فترة الانتظار هي المدة بين كل عملية إرسال لقائمة أرقام أو عملية بحث والتي تليها، وليست بين الرسائل داخل العملية نفسها. تقصر كلما ارتفعت الباقة، ولا تُحتسب إذا فشلت العملية قبل أن تبدأ. يعيد الرد الحقل next_available_at بموعد انتهاء الانتظار، وعند رفض الطلب يعيد retry_after بالثواني وavailable_at بالموعد.

الحدود على مستوى الحساب

  • كل الحدود اليومية وحدود الدقيقة وفترات الانتظار تُحسب لحسابك كله، وليس لكل مفتاح. لو كانت باقتك 2000 طلب يوميًا واستخدمتها من مفتاح واحد، فلن تعمل باقي المفاتيح حتى يتجدد العداد.
  • كل مفتاح يعمل بالباقة التي أُنشئ عليها. عند ترقية باقة API نسألك في صفحة المفاتيح: هل تنقل المفاتيح القديمة إلى الباقة الجديدة أم تبقيها على حدودها الحالية، مثلًا لو أعطيت مفتاحًا لشخص آخر وتريد حدودًا أقل له.
  • عند انتهاء اشتراك API تعمل كل المفاتيح تلقائيًا بحدود الباقة المجانية، دون أن تتوقف أو تحتاج إلى إنشاء مفاتيح جديدة.
  • تجد ما تبقى لك اليوم في الحقل meta.requests_left_today في كل رد، وفي صفحة المفاتيح بالأعلى.

باقات API

الربط مع كل أداة

واتساب الجماعي
  1. أرسل POST /wa/connect.
  2. اطلب GET /wa/status كل 3 ثوانٍ واعرض qr_image للمستخدم حتى تصبح الحالة connected.
  3. أرسل الرسالة والأرقام إلى POST /wa/send.
  4. تابع التقدم من GET /wa/status عبر الحقل job، ويمكنك الإيقاف بـ POST /wa/stop.
مستخرج بيانات العملاء
  1. اجلب أنواع الأنشطة مرة واحدة من GET /leads/categories واحفظها.
  2. أرسل المدينة أو الحي ونوع النشاط إلى POST /leads/search، ويمكنك إضافة country بكود الدولة مثل EG لنتائج أدق.
  3. قد يستغرق البحث حتى دقيقتين، فاجعل مهلة الطلب في برنامجك 150 ثانية على الأقل.
منظف الأرقام ورابط واتساب
  1. أرسل نصًا أو قائمة أرقام إلى POST /clean لتحصل على أرقام دولية نظيفة بلا تكرار.
  2. أرسل رقمًا ورسالة إلى POST /link لتحصل على رابط wa.me جاهز. الأداتان مجانيتان في كل الباقات.
مختصر الروابط
  1. أنشئ الرابط بـ POST /links واحفظ short_url.
  2. اعرض روابطك بـ GET /links وإحصائيات رابط بـ GET /links/stats?alias=...
  3. عدّل الوجهة أو أوقف الرابط بـ POST /links/update، واحذفه بـ POST /links/delete.

POST/v1/clean

تنظيف قائمة أرقام

يستخرج أرقام الهواتف من أي نص، ويوحّد صيغتها الدولية، ويحذف المكرر وغير الصالح. أداة مجانية بالكامل في كل الباقات.

المعاملات

الحقلالنوعإلزاميالوصف
textstringأحدهمانص يحتوي على أرقام (حتى 200000 حرف).
numbersstring[]أحدهماقائمة أرقام (حتى 20000 عنصر).
country_codestringلارمز الدولة للأرقام المحلية، مثل "20".
formatstringلا"digits" (افتراضي) أو "plus" لإضافة علامة +.

مثال على الطلب

curl -X POST {BASE}/clean \
  -H "Authorization: Bearer $POP_KEY" \
  -H "Content-Type: application/json" \
  -d '{"text": "Ahmed 01001234567, Mona +20 100 765 4321", "country_code": "20", "format": "plus"}'

مثال على الرد

POST/v1/leads/search

البحث عن عملاء محتملين

يجمع أسماء الأنشطة التجارية وأرقامها وعناوينها في منطقة محددة. يخضع لحد النتائج وفترة الانتظار في باقتك، ولا تُحتسب فترة الانتظار إذا لم تُعثر على نتائج.

يستغرق البحث عادة أقل من دقيقة، وقد يصل إلى دقيقتين عند ازدحام خدمة الخرائط، لذا اضبط مهلة الطلب في برنامجك على 150 ثانية على الأقل. المناطق الكبيرة جدًا يُبحث في وسطها، فاكتب اسم حي لنتائج أدق.

المعاملات

الحقلالنوعإلزاميالوصف
citystringنعمالمدينة أو الحي (حتى 80 حرفًا).
categorystringنعممعرّف من GET /v1/leads/categories.
countrystringلاكود الدولة من حرفين مثل EG أو SA، لتحديد المدينة الصحيحة عند تشابه الأسماء.
keywordstringلاكلمة يجب أن يحتويها اسم النشاط (حتى 40 حرفًا).

مثال على الطلب

curl -X POST {BASE}/leads/search \
  -H "Authorization: Bearer $POP_KEY" \
  -H "Content-Type: application/json" \
  -d '{"city": "Nasr City, Cairo", "category": "cafes"}'

مثال على الرد

  "data": {
    "area": "Nasr City, Cairo, Egypt",

POST/v1/wa/send

إرسال رسالة جماعية

يبدأ إرسال رسالة إلى قائمة أرقام من رقمك المربوط، مع متغيرات تخصّص كل رسالة. اكتب المتغير في الرسالة بهذا الشكل {name}، واكتب البدائل بهذا الشكل {Hi|Hello} لتصل إلى كل عميل صيغة مختلفة. يخضع الطلب لحد الأرقام والمتغيرات والسرعة وفترة الانتظار في باقتك.

المعاملات

الحقلالنوعإلزاميالوصف
messagestringنعمنص الرسالة (حتى 4096 حرفًا).
variablesstring[]لاأسماء المتغيرات المستخدمة في الرسالة، بحد أقصى 6 وبحسب باقتك.
recipientsarrayنعمأرقام بالصيغة الدولية، كنص مباشر أو كائن {"phone", "values"}.
recipients[].valuesarray | objectلاقيم المتغيرات بالترتيب نفسه، أو كائن مفاتيحه أسماء المتغيرات.
speedstringلا"safe" (افتراضي) أو "normal" إن كانت باقتك تسمح بها.

مثال على الطلب

curl -X POST {BASE}/wa/send \
  -H "Authorization: Bearer $POP_KEY" \
  -H "Content-Type: application/json" \
  -d '{
    "message": "{Hi|Hello} {name}, your order from {city} is ready.",
    "variables": ["name", "city"],
    "recipients": [
      { "phone": "201001234567", "values": { "name": "Ahmed", "city": "Cairo" } },
      { "phone": "201007654321", "values": ["Mona", "Giza"] }
    ],
    "speed": "safe"
  }'

مثال على الرد

{
  "ok": true,
  "data": {
    "state": "connected",
    "phone": "201000000000",
    "accepted": 2,
    "next_available_at": "2026-11-12T11:00:00.000Z",
    "job": { "id": "5b3c...", "total": 2, "done": 0, "sent": 0, "running": true, "results": [] }
  }
}

POST/v1/links

إنشاء رابط مختصر

ينشئ رابطًا قصيرًا على رابط الموقع نفسه. يُحسب من حد الروابط الجديدة يوميًا ومن الحد الكلي للروابط في باقتك. الاسم المختصر وكلمة السر وتاريخ الانتهاء متاحة حسب الباقة.

المعاملات

الحقلالنوعإلزاميالوصف
urlstringنعمالرابط الطويل، يبدأ بـ https أو http لموقع عام (حتى 2048 حرفًا).
aliasstringلاالاسم المختصر من 3 إلى 32 حرفًا صغيرًا أو رقمًا أو شرطة. إن تركته يُنشأ اسم عشوائي.
passwordstringلاكلمة سر من 4 إلى 64 حرفًا لا يفتح الرابط إلا بها. تُحفظ مشفّرة ولا تظهر مرة أخرى.
expires_atstringلاتاريخ انتهاء بصيغة ISO 8601، بعد دقيقة على الأقل.

مثال على الطلب

curl -X POST {BASE}/links \
  -H "Authorization: Bearer $POP_KEY" \
  -H "Content-Type: application/json" \

أمثلة برمجية

JavaScript (Node.js 18 أو أحدث)

const BASE = "{BASE}";
const KEY = process.env.POP_KEY;

async function pop(method, path, body) {
  const res = await fetch(BASE + path, {
    method,
    headers: { Authorization: "Bearer " + KEY, "Content-Type": "application/json" },
    body: body ? JSON.stringify(body) : undefined
  });
  const json = await res.json();
  if (!json.ok) throw new Error(json.error.code + ": " + json.error.message);
  return json.data;
}

const clean = await pop("POST", "/clean", { text: "01001234567 01007654321", country_code: "20" });
const job = await pop("POST", "/wa/send", {
  message: "{Hi|Hello} {name}",
  variables: ["name"],
  recipients: clean.numbers.map((phone, i) => ({ phone, values: [["Ahmed", "Mona"][i] || ""] }))
});
console.log(job.accepted);
